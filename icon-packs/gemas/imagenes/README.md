# Imágenes personalizadas (Gemas)

Coloca aquí tus iconos manuales en **PNG, JPG, WEBP, GIF o SVG**.

Ejemplos:

```
icon-packs/gemas/imagenes/mi-medalla.png
icon-packs/gemas/imagenes/categorias/tecnologia.png
```

Aparecerán en el admin bajo **「Elegir icono」 → Gemas → Mis imágenes**.

### GIPHY

- `giphy.svg` — icono del botón de GIF en posts, comentarios y biografía (`pack:gemas/imagenes/giphy.svg`).

También puedes poner archivos sueltos en la raíz de `gemas/` (grupo «Personalizados»).
