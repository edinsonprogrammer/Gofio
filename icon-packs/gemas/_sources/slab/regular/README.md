# Fuente Slab (Font Awesome Pro+)

Coloca aquí los SVG del pack [Slab](https://fontawesome.com/icons/packs/slab) antes de importar.

## Variantes Slab

| Carpeta | Estilo |
|---------|--------|
| `slab/regular/` | Slab · Regular |
| `slab-press/regular/` | Slab Press · Regular |
| `slab-duo/regular/` | Slab Duo · Regular |
| `slab-press-duo/regular/` | Slab Press Duo · Regular |

No hace falta tener todas: importa solo las que copies o tengas en tu Kit.

## Cómo obtener los archivos

1. Cuenta **Pro+** en [fontawesome.com/kits](https://fontawesome.com/kits).
2. Activa **Slab** (y variantes que quieras) en tu Kit.
3. Instala vía npm o descarga manual:
   ```bash
   # .env: FONTAWESOME_PACKAGE_TOKEN + FONTAWESOME_KIT_ID
   npm run install:fa-kit
   npm run import:fa-slab-gemas
   ```

Tras importar, aparecerán en el admin bajo **Slab · Regular**, etc.
